# Chapter 13: Living Without FX11 学习总结

## 核心内容
本章学习如何**不使用Effects框架**(FX11)，手动管理着色器、常量缓冲区和渲染状态。

### 关键技术
1. **着色器反射(Shader Reflection)** - ID3D11ShaderReflection
2. **手动常量缓冲区管理** - 解析HLSL结构
3. **InputLayout创建** - 从顶点着色器字节码提取
4. **状态对象管理** - 自定义RenderStates类

### 代码示例
\\\cpp
// 着色器反射
ComPtr<ID3D11ShaderReflection> pReflector;
D3DReflect(blob->GetBufferPointer(), blob->GetBufferSize(),
    IID_ID3D11ShaderReflection, (void**)pReflector.GetAddressOf());

D3D11_SHADER_DESC shaderDesc;
pReflector->GetDesc(&shaderDesc);

// 遍历常量缓冲区
for (UINT i = 0; i < shaderDesc.ConstantBuffers; ++i)
{
    ID3D11ShaderReflectionConstantBuffer* pCB = pReflector->GetConstantBufferByIndex(i);
    D3D11_SHADER_BUFFER_DESC bufferDesc;
    pCB->GetDesc(&bufferDesc);

}
\\\

### 优势
- 完全控制渲染管线
- 避免Effects框架开销
- 便于优化和调试
