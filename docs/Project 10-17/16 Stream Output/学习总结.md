# Chapter 16: Stream Output 学习总结

## 核心内容
**流输出(Stream Output, SO)**是DirectX11渲染管线的可选阶段，位于几何着色器之后，可以将顶点数据输出到缓冲区而不经过像素着色器。

### 1. SO基础

#### 管线位置
```
IA → VS → [GS] → SO → [RS → PS → OM]
                  ↓
              Buffer (GPU内存)
```

**关键特性：**
- GPU生成顶点数据并存储
- 无需CPU介入
- 适合粒子系统、布料模拟

### 2. SO配置

#### 2.1 声明SO输出
```hlsl
struct Particle
{
    float3 position : POSITION;
    float3 velocity : VELOCITY;
    float size      : SIZE;
    float age       : AGE;
    uint type       : TYPE;
};

[maxvertexcount(6)]
void GS_StreamOut(point Particle pIn[1], inout PointStream<Particle> ptStream)
{
    // 更新粒子
    pIn[0].age += gDeltaTime;
    pIn[0].position += pIn[0].velocity * gDeltaTime;
    
    // 输出到SO
    ptStream.Append(pIn[0]);
    
    // 生成新粒子
    if (pIn[0].type == EMITTER && pIn[0].age > 0.016f)
    {
        Particle newParticle;
        newParticle.position = pIn[0].position;
        newParticle.velocity = RandomVelocity();
        newParticle.age = 0.0f;
        newParticle.type = SHELL;
        ptStream.Append(newParticle);
    }
}
```

#### 2.2 C++端绑定
```cpp
// 创建SO缓冲区
D3D11_BUFFER_DESC bufDesc;
bufDesc.ByteWidth = sizeof(Particle) * MAX_PARTICLES;
bufDesc.Usage = D3D11_USAGE_DEFAULT;
bufDesc.BindFlags = D3D11_BIND_STREAM_OUTPUT | D3D11_BIND_VERTEX_BUFFER;
bufDesc.CPUAccessFlags = 0;
bufDesc.MiscFlags = 0;

ComPtr<ID3D11Buffer> pStreamOutBuffer;
HR(device->CreateBuffer(&bufDesc, nullptr, pStreamOutBuffer.GetAddressOf()));

// 绑定SO目标
UINT offset = 0;
deviceContext->SOSetTargets(1, pStreamOutBuffer.GetAddressOf(), &offset);

// 绘制（输出到SO而不是屏幕）
deviceContext->Draw(particleCount, 0);

// 解绑SO
ID3D11Buffer* nullBuffer = nullptr;
deviceContext->SOSetTargets(1, &nullBuffer, &offset);

// 将SO缓冲区作为下一帧的顶点缓冲区
deviceContext->IASetVertexBuffers(0, 1, pStreamOutBuffer.GetAddressOf(), &stride, &offset);
```

### 3. GPU粒子系统

#### 3.1 双缓冲技术
```cpp
// 两个缓冲区交替使用
ComPtr<ID3D11Buffer> m_pParticleDrawBuffer;  // 当前帧绘制
ComPtr<ID3D11Buffer> m_pParticleStreamBuffer; // 输出到这里

void UpdateParticles()
{
    // 1. 将DrawBuffer作为输入
    deviceContext->IASetVertexBuffers(0, 1, m_pParticleDrawBuffer.GetAddressOf(), ...);
    
    // 2. 输出到StreamBuffer
    deviceContext->SOSetTargets(1, m_pParticleStreamBuffer.GetAddressOf(), ...);
    
    // 3. 运行更新GS
    deviceContext->GSSetShader(m_pUpdateGS.Get(), nullptr, 0);
    deviceContext->Draw(particleCount, 0);
    
    // 4. 交换缓冲区
    std::swap(m_pParticleDrawBuffer, m_pParticleStreamBuffer);
}
```

#### 3.2 查询粒子数量
```cpp
// 创建查询对象
D3D11_QUERY_DESC queryDesc;
queryDesc.Query = D3D11_QUERY_SO_STATISTICS;
queryDesc.MiscFlags = 0;

ComPtr<ID3D11Query> pSOQuery;
device->CreateQuery(&queryDesc, pSOQuery.GetAddressOf());

// 开始查询
deviceContext->Begin(pSOQuery.Get());
deviceContext->Draw(...); // SO输出
deviceContext->End(pSOQuery.Get());

// 获取结果
D3D11_QUERY_DATA_SO_STATISTICS soStats;
while (deviceContext->GetData(pSOQuery.Get(), &soStats, sizeof(soStats), 0) == S_FALSE)
    Sleep(1); // 等待GPU完成

UINT particleCount = (UINT)soStats.NumPrimitivesWritten;
```

### 4. 完整粒子系统流程

```cpp
void DrawParticles()
{
    // Pass 1: 更新粒子（使用SO）
    deviceContext->IASetVertexBuffers(0, 1, m_pParticleDrawBuffer.GetAddressOf(), ...);
    deviceContext->SOSetTargets(1, m_pParticleStreamBuffer.GetAddressOf(), ...);
    deviceContext->GSSetShader(m_pUpdateGS.Get(), nullptr, 0);
    deviceContext->PSSetShader(nullptr, nullptr, 0); // 不需要PS
    deviceContext->Draw(m_ParticleCount, 0);
    
    // 查询新粒子数量
    D3D11_QUERY_DATA_SO_STATISTICS soStats;
    // ... 获取soStats ...
    m_ParticleCount = (UINT)soStats.NumPrimitivesWritten;
    
    // Pass 2: 渲染粒子（不使用SO）
    ID3D11Buffer* nullBuffer = nullptr;
    deviceContext->SOSetTargets(1, &nullBuffer, &offset);
    deviceContext->IASetVertexBuffers(0, 1, m_pParticleStreamBuffer.GetAddressOf(), ...);
    deviceContext->GSSetShader(m_pRenderGS.Get(), nullptr, 0);
    deviceContext->PSSetShader(m_pParticlePS.Get(), nullptr, 0);
    deviceContext->Draw(m_ParticleCount, 0);
    
    // 交换缓冲区
    std::swap(m_pParticleDrawBuffer, m_pParticleStreamBuffer);
}
```

### 5. 性能优化

**SO开销：**
- 写入GPU内存开销
- 双缓冲内存占用
- 查询有轻微延迟

**优化建议：**
1. 限制粒子数量上限
2. 使用合适的粒子大小结构（避免padding）
3. 批量处理粒子生成
4. 考虑Compute Shader替代（DX11.1+）

### 6. 常见问题

**Q1: 为什么粒子数量不正确？**
A: 检查SO查询是否正确等待GPU完成，使用`GetData`循环等待

**Q2: 缓冲区大小如何确定？**
A: 预估最大粒子数×2（考虑粒子生成），使用`D3D11_USAGE_DEFAULT`

**Q3: SO和Compute Shader如何选择？**
A: DX11用SO，DX11.1+推荐CS（更灵活，性能更好）
