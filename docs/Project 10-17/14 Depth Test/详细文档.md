## 1. 核心概念：深度测试与深度写入

### 1.1 深度测试 (Depth Test)

**深度测试**是3D渲染管线中的关键步骤，用于确定片元（像素）的前后关系，确保正确的遮挡效果。

```
场景示例：
          相机
           │
           │ 观察方向
           ↓
    ┌──────────┐  ← 近物体（深度值小，如0.2）
    │ 红色立方体│
    └──────────┘
         ↓
    ┌──────────┐  ← 远物体（深度值大，如0.8）
    │ 蓝色立方体│
    └──────────┘

深度测试流程：
1. 绘制红色立方体：深度值0.2写入深度缓冲区
2. 绘制蓝色立方体：深度值0.8 > 0.2 → 测试失败 → 不绘制该像素
3. 结果：红色立方体遮挡蓝色立方体（正确！）
```

**深度测试公式**：

```cpp
// D3D11_COMPARISON_LESS（默认）
if (incomingDepth < depthBufferValue)
{
    // 测试通过：绘制片元，更新深度缓冲区
    colorBuffer[pixel] = fragmentColor;
    depthBuffer[pixel] = incomingDepth;
}
else
{
    // 测试失败：丢弃片元
    discard;
}
```

### 1.2 深度写入 (Depth Write)

**深度写入**控制是否将片元的深度值写入深度缓冲区。

```cpp
// 深度测试和深度写入是两个独立的控制

// 情况1：深度测试ON + 深度写入ON（默认）
DepthEnable = TRUE;
DepthWriteMask = D3D11_DEPTH_WRITE_MASK_ALL;
// 行为：测试通过的片元会更新深度缓冲区

// 情况2：深度测试ON + 深度写入OFF
DepthEnable = TRUE;
DepthWriteMask = D3D11_DEPTH_WRITE_MASK_ZERO;
// 行为：测试通过的片元不会更新深度缓冲区
// 用途：绘制半透明物体、粒子效果

// 情况3：深度测试OFF + 深度写入OFF
DepthEnable = FALSE;
DepthWriteMask = D3D11_DEPTH_WRITE_MASK_ZERO;
// 行为：片元总是绘制，不管深度
// 用途：UI、HUD、天空盒

// 情况4：深度测试OFF + 深度写入ON（不常见）
// 行为：片元总是绘制，并写入深度
// 用途：预Z-Pass（提前填充深度缓冲区）
```

### 1.3 Chapter 14 的核心问题

本章引入了**闪电动画**（60帧循环播放的粒子效果），遇到以下挑战：

**问题1：Z-Fighting（深度冲突）**

```cpp
// 场景设置：
// - 地板：Y = -1.0
// - 闪电动画：Y = 2.01（圆柱体，半径4.0，高度4.0）
// - 木箱：Y = 0.01

// 问题：闪电动画与地板在相同位置（Y ≈ 0）
// 深度值非常接近，导致像素交替显示（闪烁）

// 错误示例：
m_BoltAnim.GetTransform().SetPosition(0.0f, 0.0f, 0.0f);
// 结果：闪电动画与地板深度值冲突 → Z-Fighting

// 解决方案：抬高位置
m_BoltAnim.GetTransform().SetPosition(0.0f, 2.01f, 0.0f);
// 结果：深度值分离，避免冲突
```

**问题2：半透明粒子的深度问题**

```cpp
// 闪电动画特点：
// 1. 半透明（需要Alpha混合）
// 2. 应该能"透过"看到背后的物体
// 3. 多个闪电片元可能重叠

// ❌ 错误做法：启用深度写入
DepthEnable = TRUE;
DepthWriteMask = D3D11_DEPTH_WRITE_MASK_ALL;
BlendEnable = TRUE;

// 问题：
// - 第1个闪电片元写入深度值0.5
// - 第2个闪电片元深度值0.6 > 0.5 → 被剔除
// - 结果：闪电动画后面部分消失（错误！）

// ✅ 正确做法：关闭深度写入
DepthEnable = TRUE;  // 仍然测试深度（被不透明物体遮挡）
DepthWriteMask = D3D11_DEPTH_WRITE_MASK_ZERO;  // 不写入深度
BlendEnable = TRUE;

// 行为：
// - 第1个闪电片元通过深度测试 → 绘制 → 不更新深度
// - 第2个闪电片元仍然通过深度测试 → 绘制 → 不更新深度
// - 结果：闪电动画完整显示，可以与背景混合（正确！）
```

### 1.4 深度值的精度分布

```cpp
// DirectX使用非线性深度分布（透视投影）

// 深度缓冲区格式：
// - DXGI_FORMAT_D24_UNORM_S8_UINT：24位深度 + 8位模板
// - 深度范围：[0.0, 1.0]（0=近平面，1=远平面）

// 非线性分布特点：
// - 近处精度高（大部分位用于近距离）
// - 远处精度低（少量位用于远距离）

// 示例：近平面=0.5，远平面=1000.0
float nearZ = 0.5f;
float farZ = 1000.0f;

// 世界空间 → 深度缓冲区值
// Z=0.5  → depth≈0.000  （近平面）
// Z=1.0  → depth≈0.0005 （相机前方0.5米）
// Z=10.0 → depth≈0.005  （10米远）
// Z=100.0→ depth≈0.05   （100米远）
// Z=500.0→ depth≈0.5    （500米远）
// Z=1000 → depth≈1.0    （远平面）

// 可以看到：
// - 前10米占用0.5%的精度
// - 后990米占用99.5%的精度
// - 这就是为什么近平面不能太小！

// ❌ 坏的设置
camera.SetFrustum(fov, aspect, 0.001f, 10000.0f);
// 近平面太小 → 精度浪费在极近处
// 远平面太大 → 远处精度不足 → Z-Fighting

// ✅ 好的设置
camera.SetFrustum(fov, aspect, 0.5f, 1000.0f);
// 合理的范围 → 最佳精度分配
```

### 1.5 深度测试的比较函数

```cpp
// D3D11_COMPARISON_FUNC枚举

D3D11_COMPARISON_NEVER         // 总是失败（不绘制）
D3D11_COMPARISON_LESS          // <  默认，标准深度测试
D3D11_COMPARISON_EQUAL         // == 深度值完全相等
D3D11_COMPARISON_LESS_EQUAL    // <= 允许相等（常用于天空盒）
D3D11_COMPARISON_GREATER       // >  反向深度测试
D3D11_COMPARISON_NOT_EQUAL     // != 不等于
D3D11_COMPARISON_GREATER_EQUAL // >= 反向深度测试+允许相等
D3D11_COMPARISON_ALWAYS        // 总是通过（忽略深度）

// 使用示例：

// 1. 标准不透明物体
dsDesc.DepthFunc = D3D11_COMPARISON_LESS;

// 2. 天空盒（总是最远）
dsDesc.DepthFunc = D3D11_COMPARISON_LESS_EQUAL;
// 天空盒在VS中设置depth=1.0（最远）
// 如果场景中所有物体都绘制完了，depth buffer = 1.0的区域可以绘制天空盒

// 3. 反向Z技巧（提高精度）
dsDesc.DepthFunc = D3D11_COMPARISON_GREATER;
// 反转深度范围：近=1.0，远=0.0
// 优势：更均匀的精度分布（减少Z-Fighting）

// 4. 调试：总是绘制
dsDesc.DepthFunc = D3D11_COMPARISON_ALWAYS;
// 用于调试，查看被遮挡的物体
```

## 2. 深度缓冲区原理

### 2.1 深度缓冲区的创建

```cpp
// GameApp::Init() 中创建深度缓冲区（D3DApp基类完成）

// 步骤1：创建深度/模板纹理
D3D11_TEXTURE2D_DESC depthStencilDesc;
ZeroMemory(&depthStencilDesc, sizeof(depthStencilDesc));
depthStencilDesc.Width = clientWidth;
depthStencilDesc.Height = clientHeight;
depthStencilDesc.MipLevels = 1;
depthStencilDesc.ArraySize = 1;
depthStencilDesc.Format = DXGI_FORMAT_D24_UNORM_S8_UINT;  // 24位深度+8位模板
depthStencilDesc.SampleDesc.Count = 1;
depthStencilDesc.SampleDesc.Quality = 0;
depthStencilDesc.Usage = D3D11_USAGE_DEFAULT;
depthStencilDesc.BindFlags = D3D11_BIND_DEPTH_STENCIL;
depthStencilDesc.CPUAccessFlags = 0;
depthStencilDesc.MiscFlags = 0;

ComPtr<ID3D11Texture2D> depthStencilBuffer;
HR(device->CreateTexture2D(&depthStencilDesc, nullptr, depthStencilBuffer.GetAddressOf()));

// 步骤2：创建深度/模板视图
D3D11_DEPTH_STENCIL_VIEW_DESC dsvDesc;
ZeroMemory(&dsvDesc, sizeof(dsvDesc));
dsvDesc.Format = DXGI_FORMAT_D24_UNORM_S8_UINT;
dsvDesc.ViewDimension = D3D11_DSV_DIMENSION_TEXTURE2D;
dsvDesc.Texture2D.MipSlice = 0;

HR(device->CreateDepthStencilView(depthStencilBuffer.Get(), &dsvDesc,
                                   m_pDepthStencilView.GetAddressOf()));

// 步骤3：绑定到输出合并阶段
context->OMSetRenderTargets(1, m_pRenderTargetView.GetAddressOf(),
                             m_pDepthStencilView.Get());
```

**深度格式选择**：

```cpp
// 常见深度格式

// DXGI_FORMAT_D24_UNORM_S8_UINT（最常用）
// - 24位深度（UNORM：[0.0, 1.0]归一化）
// - 8位模板（UINT：[0, 255]整数）
// - 总计：32位（4字节）
// - 适用：大多数场景

// DXGI_FORMAT_D32_FLOAT
// - 32位浮点深度
// - 无模板
// - 优势：更高精度，减少Z-Fighting
// - 缺点：无法使用模板测试

// DXGI_FORMAT_D32_FLOAT_S8X24_UINT
// - 32位浮点深度
// - 8位模板 + 24位填充
// - 总计：64位（8字节）
// - 优势：最高精度+模板测试
// - 缺点：占用更多内存和带宽

// DXGI_FORMAT_D16_UNORM
// - 16位深度
// - 无模板
// - 优势：节省内存和带宽
// - 缺点：精度低，容易Z-Fighting
// - 适用：移动平台、性能优先场景
```

### 2.2 深度缓冲区的清除

```cpp
// 每帧开始时清除深度缓冲区

void GameApp::DrawScene()
{
    // 清除颜色缓冲区为黑色
    m_pd3dImmediateContext->ClearRenderTargetView(
        m_pRenderTargetView.Get(),
        reinterpret_cast<const float*>(&Colors::Black));

    // 清除深度缓冲区为1.0（最远），模板缓冲区为0
    m_pd3dImmediateContext->ClearDepthStencilView(
        m_pDepthStencilView.Get(),
        D3D11_CLEAR_DEPTH | D3D11_CLEAR_STENCIL,  // 清除标志
        1.0f,   // 深度值（1.0=最远）
        0);     // 模板值（0=背景）

    // ... 绘制场景
}

// 清除标志选项：
// D3D11_CLEAR_DEPTH   - 仅清除深度
// D3D11_CLEAR_STENCIL - 仅清除模板
// D3D11_CLEAR_DEPTH | D3D11_CLEAR_STENCIL - 两者都清除

// 清除值的含义：
// - 深度值1.0：代表最远距离（远平面）
// - 任何新绘制的片元深度值（0.0-1.0）都会小于1.0
// - 因此第一次深度测试总是通过

// 特殊情况：反向Z
// ClearDepthStencilView(dsv, D3D11_CLEAR_DEPTH, 0.0f, 0);
// 如果使用反向深度（near=1.0, far=0.0），清除值应该是0.0
```

### 2.3 深度缓冲区的读写流程

```
渲染管线中的深度测试位置：

Input Assembler (IA) → Vertex Shader (VS) → Rasterizer (RS)
    ↓
Pixel Shader (PS) → Output Merger (OM)
                        ↓
                    深度测试发生在这里！
                        ↓
    ┌───────────────────┴───────────────────┐
    │                                       │
    │  1. 读取深度缓冲区当前值              │
    │     currentDepth = depthBuffer[x, y]  │
    │                                       │
    │  2. 比较片元深度值                     │
    │     if (fragmentDepth < currentDepth) │
    │                                       │
    │  3. 测试通过                          │
    │     - 写入颜色缓冲区                   │
    │     - 可选：写入深度缓冲区             │
    │                                       │
    │  4. 测试失败                          │
    │     - 丢弃片元                        │
    │     - 不写入任何缓冲区                 │
    │                                       │
    └───────────────────────────────────────┘
```

**Early-Z优化**（硬件自动）：

```cpp
// 现代GPU支持Early-Z：在PS之前进行深度测试

// 传统流程：
// VS → RS → PS → OM（深度测试）
// 问题：即使片元被剔除，PS仍然执行（浪费）

// Early-Z流程：
// VS → RS → Early深度测试 → PS → OM（最终深度测试）
// 优势：深度测试失败的片元不会执行PS（节省）

// Early-Z的条件：
// 1. PS不能修改深度值（SV_Depth）
// 2. PS不能使用discard/clip（会破坏深度值预测）
// 3. 深度测试函数必须是LESS或LESS_EQUAL

// 例子：
float4 PS_EarlyZ(VertexOut pin) : SV_Target
{
    // ✅ 可以使用Early-Z
    float4 color = g_Tex.Sample(g_Sam, pin.tex);
    return color;
}

float4 PS_NoEarlyZ(VertexOut pin) : SV_Target
{
    // ❌ 无法使用Early-Z
    float4 color = g_Tex.Sample(g_Sam, pin.tex);
    clip(color.a - 0.5f);  // discard破坏Early-Z
    return color;
}

float4 PS_NoEarlyZ2(VertexOut pin, out float depth : SV_Depth) : SV_Target
{
    // ❌ 无法使用Early-Z
    depth = pin.posH.z * 0.5f;  // 修改深度值
    return float4(1, 0, 0, 1);
}
```

### 2.4 深度精度问题

```cpp
// 深度精度计算公式（透视投影）

// NDC深度值（非线性）
float depthNDC = (farZ * (viewZ - nearZ)) / (viewZ * (farZ - nearZ));

// 深度精度（单位深度的精度变化）
float depthPrecision = (farZ * nearZ) / (viewZ * viewZ * (farZ - nearZ));

// 示例计算：
float nearZ = 0.5f;
float farZ = 1000.0f;

// 在不同距离的精度（24位深度）
float precision1m   = CalcPrecision(1.0f);    // ≈ 0.00001（极高）
float precision10m  = CalcPrecision(10.0f);   // ≈ 0.001（高）
float precision100m = CalcPrecision(100.0f);  // ≈ 0.1（中）
float precision500m = CalcPrecision(500.0f);  // ≈ 2.5（低）

// 可以看到：
// - 1米处精度：0.01毫米（远超需要）
// - 500米处精度：2.5米（可能不够）

// Z-Fighting发生条件：
// 两个表面的世界空间距离 < 当前位置的深度精度
// 
// 例如：在500米处，两个相距1米的表面会发生Z-Fighting
//       因为深度精度（2.5米）> 实际距离（1米）
```

## 3. 深度状态配置详解

### 3.1 D3D11_DEPTH_STENCIL_DESC结构体

```cpp
// 完整的深度/模板状态描述

struct D3D11_DEPTH_STENCIL_DESC
{
    // === 深度测试配置 ===
    BOOL DepthEnable;                   // 是否启用深度测试
    D3D11_DEPTH_WRITE_MASK DepthWriteMask;  // 深度写入掩码
    D3D11_COMPARISON_FUNC DepthFunc;    // 深度比较函数

    // === 模板测试配置 ===
    BOOL StencilEnable;                 // 是否启用模板测试
    UINT8 StencilReadMask;              // 模板读取掩码
    UINT8 StencilWriteMask;             // 模板写入掩码

    // === 正面模板操作 ===
    D3D11_DEPTH_STENCILOP_DESC FrontFace;

    // === 背面模板操作 ===
    D3D11_DEPTH_STENCILOP_DESC BackFace;
};

// 模板操作描述
struct D3D11_DEPTH_STENCILOP_DESC
{
    D3D11_STENCIL_OP StencilFailOp;      // 模板测试失败时的操作
    D3D11_STENCIL_OP StencilDepthFailOp; // 模板测试通过但深度测试失败
    D3D11_STENCIL_OP StencilPassOp;      // 模板和深度测试都通过
    D3D11_COMPARISON_FUNC StencilFunc;   // 模板比较函数
};
```

### 3.2 Chapter 14 新增的深度状态

#### 3.2.1 DSSNoDepthTest - 关闭深度测试

```cpp
// RenderStates.cpp 中定义

void RenderStates::InitAll(ID3D11Device* device)
{
    // ... 其他状态

    // 关闭深度测试（用于闪电动画，总是绘制）
    D3D11_DEPTH_STENCIL_DESC noDepthTestDesc;
    noDepthTestDesc.DepthEnable = FALSE;  // ← 关闭深度测试
    noDepthTestDesc.DepthWriteMask = D3D11_DEPTH_WRITE_MASK_ZERO;  // 不写入深度
    noDepthTestDesc.DepthFunc = D3D11_COMPARISON_LESS;
    noDepthTestDesc.StencilEnable = FALSE;  // 不使用模板
    noDepthTestDesc.StencilReadMask = D3D11_DEFAULT_STENCIL_READ_MASK;
    noDepthTestDesc.StencilWriteMask = D3D11_DEFAULT_STENCIL_WRITE_MASK;
    // FrontFace和BackFace使用默认值
    HR(device->CreateDepthStencilState(&noDepthTestDesc, DSSNoDepthTest.GetAddressOf()));

    // 使用场景：
    // - UI元素（总是显示在最前面）
    // - 天空盒/远景（总是显示在最后面）
    // - 粒子效果（不参与深度测试，自由混合）
    // - 调试绘制（穿透场景显示）
}
```

**使用示例**：

```cpp
// BasicEffect.cpp - SetDrawBoltAnimNoDepthTest

void BasicEffect::SetDrawBoltAnimNoDepthTest(ID3D11DeviceContext* deviceContext)
{
    deviceContext->IASetPrimitiveTopology(D3D11_PRIMITIVE_TOPOLOGY_TRIANGLELIST);
```

#### 3.2.2 DSSNoDepthWrite - 关闭深度写入

```cpp
// RenderStates.cpp

void RenderStates::InitAll(ID3D11Device* device)
{
    // 关闭深度写入，但保留深度测试
    D3D11_DEPTH_STENCIL_DESC noDepthWriteDesc;
    noDepthWriteDesc.DepthEnable = TRUE;  // ← 启用深度测试
    noDepthWriteDesc.DepthWriteMask = D3D11_DEPTH_WRITE_MASK_ZERO;  // ← 不写入深度
    noDepthWriteDesc.DepthFunc = D3D11_COMPARISON_LESS;
    noDepthWriteDesc.StencilEnable = FALSE;
    noDepthWriteDesc.StencilReadMask = D3D11_DEFAULT_STENCIL_READ_MASK;
    noDepthWriteDesc.StencilWriteMask = D3D11_DEFAULT_STENCIL_WRITE_MASK;
    HR(device->CreateDepthStencilState(&noDepthWriteDesc, DSSNoDepthWrite.GetAddressOf()));

    // 使用场景：
    // - 半透明物体（需要混合多个片元）
    // - 粒子系统（多个粒子重叠）
    // - 玻璃/水面（看到背后物体）
    // - 云层/烟雾（体积效果）
}
```

**关闭深度写入的原理**：

```
场景：绘制两个重叠的半透明粒子

粒子A（深度0.5）     粒子B（深度0.6）
     ↓                    ↓
┌────────┐          ┌────────┐
│   ░░   │          │   ▒▒   │
│  ░░░░  │          │  ▒▒▒▒  │
│   ░░   │          │   ▒▒   │
└────────┘          └────────┘
     重叠区域

=== 启用深度写入（错误）===
1. 绘制粒子A（深度0.5）
   - 深度测试通过（0.5 < 1.0）
   - 颜色：colorBuffer = blendColor(background, particleA)
   - 深度：depthBuffer = 0.5  ← 写入深度

2. 绘制粒子B（深度0.6）
   - 深度测试失败（0.6 > 0.5）← 被粒子A遮挡！
   - 丢弃片元 → 粒子B不显示
   
结果：粒子B消失（错误！应该混合）

=== 关闭深度写入（正确）===
1. 绘制粒子A（深度0.5）
   - 深度测试通过（0.5 < 1.0）
   - 颜色：colorBuffer = blendColor(background, particleA)
   - 深度：depthBuffer = 1.0  ← 不写入，保持原值

2. 绘制粒子B（深度0.6）
   - 深度测试通过（0.6 < 1.0）← 仍然通过！
   - 颜色：colorBuffer = blendColor(colorBuffer, particleB)
   - 深度：depthBuffer = 1.0  ← 不写入

结果：粒子A和B都显示并混合（正确！）
```

### 4.3 Z-Fighting问题详解

**问题场景**：

```cpp
// ❌ 错误设置
m_Floor.GetTransform().SetPosition(0.0f, -1.0f, 0.0f);  // 地板
m_BoltAnim.GetTransform().SetPosition(0.0f, 0.0f, 0.0f);  // 闪电动画

// 闪电圆柱体：底部Y = 0 - 2 = -2，顶部Y = 0 + 2 = 2
// 地板平面：Y = -1
// 
// 冲突区域：闪电圆柱体（Y = -2 到 2）与地板（Y = -1）
// 在Y ≈ -1附近，深度值非常接近
```

**深度值计算**：

```cpp
// 假设摄像机在(0, 5, -10)，看向(0, 0, 0)

// 地板像素的深度值（Y = -1）
float3 floorPos = float3(0, -1, 0);
float4 floorClipPos = mul(float4(floorPos, 1), viewProj);
float floorDepth = floorClipPos.z / floorClipPos.w;  // ≈ 0.55（24位精度）

// 闪电像素的深度值（Y = -1附近）
float3 boltPos = float3(0, -0.99, 0);  // 闪电圆柱体表面
float4 boltClipPos = mul(float4(boltPos, 1), viewProj);
float boltDepth = boltClipPos.z / boltClipPos.w;  // ≈ 0.5499999（24位精度）

// 深度差异：|0.55 - 0.5499999| = 0.0000001
// 
// 24位深度缓冲区精度：1 / (2^24) ≈ 0.00000006
// 
// 结论：深度差异 < 精度 → Z-Fighting！
```

**Z-Fighting视觉效果**：

```
理想情况（深度值分离）：
┌────────────────┐
│   闪电动画     │  ← 深度值0.50（更近）
├────────────────┤
│   地板         │  ← 深度值0.60（更远）
└────────────────┘
结果：闪电完全遮挡地板（正确）

Z-Fighting（深度值冲突）：
┌────────────────┐
│ ░▒░▒地▒░闪░▒  │  ← 深度值≈0.55±0.000001
│ ▒░▒░板░▒电▒░  │    哪个像素在前取决于浮点误差
└────────────────┘
结果：像素交替显示，产生闪烁（错误！）
```

**解决方案对比**：

```cpp
// 方案1：调整位置（本章采用）
m_BoltAnim.GetTransform().SetPosition(0.0f, 2.01f, 0.0f);
// 闪电底部：Y = 2.01 - 2 = 0.01（地板上方）
// 优势：简单有效
// 缺点：需要手动调整位置

// 方案2：深度偏移（Polygon Offset）

rsDesc.DepthBias = 1000;  // 整数偏移
rsDesc.DepthBiasClamp = 0.0f;
rsDesc.SlopeScaledDepthBias = 1.0f;
// 优势：无需改变几何位置
// 缺点：需要调整参数，可能影响其他渲染

// 方案3：使用更高精度深度缓冲区
DXGI_FORMAT_D32_FLOAT_S8X24_UINT  // 32位浮点深度
// 优势：精度最高
// 缺点：占用更多内存

// 方案4：关闭闪电的深度写入（本章也采用）

// 优势：闪电不会与地板冲突
// 缺点：闪电不会遮挡其他物体
```

```cpp
// - 物体关于Z=10平面反射
// - 正面变成背面（剔除反转）
```

**反射空间变换**：

```
正常空间：
         Z=10（镜子平面）
              │
         木箱 │
         (0,0,5) │
              │
          相机│
         (0,5,-10)
              ↓ 观察方向

反射空间（关于Z=10反射）：
              │ Z=10
              │
              │     反射的木箱
              │     (0,0,15)
              │     ↑
              │  对称位置
              ↓
          相机
         (0,5,-10)（相机不变）

反射公式：
P_reflected = P - 2 * dot(P - PlanePoint, PlaneNormal) * PlaneNormal

例如：木箱从 Z=5 反射到 Z=15
Z_reflected = 5 - 2 * (5 - 10) * (-1) = 5 - 2 * (-5) * (-1) = 5 - 10 = -5
等等，计算错了！应该是：
Z_reflected = 5 - 2 * dot((0,0,5) - (0,0,10), (0,0,-1)) * (0,0,-1)
            = 5 - 2 * (-5) * (0,0,-1)
            = 5 - (0,0,10)
            = (0,0,15) ✓

DirectXMath提供的XMMatrixReflect会处理这些计算。
```

**阴影投影原理**：

```
反射空间中的投影：
           反射光源(0, 10, 30)
               ╱│╲
              ╱ │ ╲
             ╱  │  ╲
            ╱   │   ╲
           ╱    │    ╲
          ╱反射木箱   ╲
         ╱ (0, 0, 15) ╲
        ╱──────┼──────╲
       ╱       │阴影  ╲
    地板(Y=0.99)│       ╲
    ────────────┴─────────────

投影矩阵将木箱顶点投影到Y=0.99平面：
V_shadow = V + t * (LightPos - V)
其中 t 使得 V_shadow.y = 0.99
```

**Alpha混合公式**：

```cpp
// 混合方程：
finalColor = srcColor * srcBlend + destColor * destBlend

// 本章的混合状态：
srcBlend = SRC_ALPHA = 0.5  （来自材质的alpha）
destBlend = INV_SRC_ALPHA = 1 - 0.5 = 0.5

// 计算：
finalColor = mirrorColor * 0.5 + reflectionColor * 0.5

// 例子：
mirrorColor = (0.5, 0.5, 1.0)  // 浅蓝色镜子
reflectionColor = (1.0, 0, 0)  // 反射的红色木箱

finalColor = (0.5, 0.5, 1.0) * 0.5 + (1.0, 0, 0) * 0.5
           = (0.25, 0.25, 0.5) + (0.5, 0, 0)
           = (0.75, 0.25, 0.5)  // 混合后的紫红色
```

```cpp
// BasicEffect.cpp

void BasicEffect::SetDrawBoltAnimNoDepthTest(ID3D11DeviceContext* deviceContext)
{
    // 输入布局：3D顶点（位置、法线、纹理坐标）
    deviceContext->IASetPrimitiveTopology(D3D11_PRIMITIVE_TOPOLOGY_TRIANGLELIST);
    deviceContext->IASetInputLayout(pImpl->m_pVertexLayout3D.Get());

    // 顶点着色器：3D基础VS
    deviceContext->VSSetShader(pImpl->m_pVertexShader3D.Get(), nullptr, 0);

    // 光栅化状态：无剔除（双面渲染）
    deviceContext->RSSetState(RenderStates::RSNoCull.Get());

    // 像素着色器：3D基础PS
    deviceContext->PSSetShader(pImpl->m_pPixelShader3D.Get(), nullptr, 0);

    // 纹理采样器：线性过滤+包裹寻址
    deviceContext->PSSetSamplers(0, 1, RenderStates::SSLinearWrap.GetAddressOf());

    // ⚠️ 深度/模板状态：关闭深度测试
    deviceContext->OMSetDepthStencilState(RenderStates::DSSNoDepthTest.Get(), 0);

    deviceContext->OMSetBlendState(RenderStates::BSTransparent.Get(), nullptr, 0xFFFFFFFF);
}
```

### 6.3 为什么使用RSNoCull（无剔除）

```cpp
// 闪电动画使用圆柱体几何

// ❌ 使用背面剔除（默认）
deviceContext->RSSetState(RenderStates::RSCullClockWise.Get());

// 问题：
// 圆柱体是从内部观察时：
// - 如果相机在圆柱体内部 → 看到内表面（逆时针三角形）
// - 如果相机在圆柱体外部 → 看到外表面（顺时针三角形）
// 
// 闪电动画的圆柱体半径较大（4.0），相机可能穿过闪电
// 如果启用剔除，穿过时会看到闪电消失（不自然）

// ✅ 使用无剔除（双面渲染）
deviceContext->RSSetState(RenderStates::RSNoCull.Get());

// 优势：
// - 相机在任何位置都能看到闪电
// - 从内部和外部都能看到圆柱体表面
// - 半透明效果更自然（可以看到闪电的"内部"）

// 缺点：
// - 渲染两倍的三角形（性能略降）
// - 对于半透明的粒子效果，这是可以接受的
```

## 7. Z-Fighting问题与解决方案

### 7.1 Z-Fighting的成因

```cpp
// Z-Fighting（深度冲突）的根本原因：深度缓冲区精度有限

// 场景：两个表面非常接近

// 表面A：Y = 0.0
// 表面B：Y = 0.0001  （仅相距0.1毫米）

// 投影后的深度值（24位精度）：
// 表面A：depth = 0.55000000
// 表面B：depth = 0.55000012

// 24位深度缓冲区的量化：
// 最小可表示差异：1 / (2^24) ≈ 0.0000000596

// 问题：
// 如果浮点计算误差 > 最小可表示差异
// 则两个表面的深度值可能"交换"（取决于舍入误差）

// 结果：
// - 像素A：深度值 = 0.55000010 → 表面A在前
// - 像素B：深度值 = 0.55000005 → 表面B在前
// - 像素C：深度值 = 0.55000008 → 表面A在前
// 
// 最终效果：表面A和B的像素交替显示 → 闪烁伪影
```

**Z-Fighting的触发条件**：

```cpp
// 条件1：表面距离 < 深度精度

float surfaceDistance = |Y_A - Y_B|;
float depthPrecision = CalculateDepthPrecision(viewZ);

if (surfaceDistance < depthPrecision)
{
    // Z-Fighting可能发生
}

// 条件2：距离相机越远，精度越低

// 近处（1米）：精度 ≈ 0.00001米（0.01毫米）
// 中等（100米）：精度 ≈ 0.1米（10厘米）
// 远处（1000米）：精度 ≈ 10米

// 因此，Z-Fighting更容易在远距离发生

// 条件3：近平面/远平面比例过大

float ratio = farPlane / nearPlane;

// 比例过大 → 精度分布不均
// 例如：near=0.01, far=10000 → ratio=1,000,000 → 严重的Z-Fighting
// 推荐：near=0.5, far=1000 → ratio=2,000 → 较少的Z-Fighting
```

### 7.2 Chapter 14 中的Z-Fighting场景

### 7.3 解决方案1：位置偏移

```cpp
// 最简单的方法：调整物体位置，确保有足够的空间分离

// 策略：
// - 确定基准平面（通常是地板）
// - 其他物体在基准平面上方增加小偏移（epsilon）

float epsilon = 0.01f;  // 1厘米偏移

// 地板：基准
m_Floor.GetTransform().SetPosition(0, -1, 0);

// 木箱：略高于地板
m_WoodCrate.GetTransform().SetPosition(0, epsilon, 0);

// 闪电：更高
m_BoltAnim.GetTransform().SetPosition(0, 2.01f, 0);

// 注意：
// - epsilon值需要根据场景规模调整
// - 小场景（房间）：0.01 - 0.1
// - 大场景（室外）：0.1 - 1.0
// - 考虑相机距离和深度精度
```

**epsilon值的计算**：

```cpp
// 根据深度精度计算合理的epsilon

float CalculateEpsilon(float viewZ, float nearZ, float farZ)
{
    // 深度精度公式（简化版）
    float precision = (farZ * nearZ) / (viewZ * viewZ * (farZ - nearZ));
    
    // epsilon应该是精度的数倍（安全系数）
    float safetyFactor = 10.0f;
    float epsilon = precision * safetyFactor;
    
    return epsilon;
}

// 例子：
// viewZ = 10米, nearZ = 0.5, farZ = 1000
// precision ≈ 0.0005
// epsilon = 0.0005 * 10 = 0.005（5毫米）

// 实际使用：
// 通常直接使用经验值（0.01）就足够了
// 除非场景非常大或相机距离变化很大
```

### 7.4 解决方案2：深度偏移（Depth Bias）

```cpp
// 使用光栅化状态的DepthBias参数

D3D11_RASTERIZER_DESC rsDesc;
rsDesc.FillMode = D3D11_FILL_SOLID;
rsDesc.CullMode = D3D11_CULL_BACK;
rsDesc.FrontCounterClockwise = FALSE;
rsDesc.DepthClipEnable = TRUE;
rsDesc.ScissorEnable = FALSE;
rsDesc.MultisampleEnable = FALSE;
rsDesc.AntialiasedLineEnable = FALSE;

// === 深度偏移参数 ===
rsDesc.DepthBias = 1000;                // 整数偏移量
rsDesc.DepthBiasClamp = 0.0f;          // 最大偏移量（0=无限制）
rsDesc.SlopeScaledDepthBias = 1.0f;    // 斜率缩放偏移

// 深度偏移公式：
// finalDepth = originalDepth + DepthBias * r + SlopeScaledDepthBias * maxSlope
// 其中：
// - r：深度缓冲区的最小可表示差异
// - maxSlope：多边形的最大斜率

// 例子：
// DepthBias = 1000
// r = 1 / (2^24) ≈ 0.00000006
// offset = 1000 * 0.00000006 = 0.00006

// 适用场景：
// - 阴影贴图（避免"阴影痤疮"）
// - 贴花（decals）
// - 叠加几何（overlay geometry）
```

**DepthBias的优缺点**：

```cpp
// ✅ 优势：
// 1. 无需修改顶点位置（保持几何精确）
// 2. 可以动态调整（通过切换光栅化状态）
// 3. 考虑多边形斜率（更智能）

// ❌ 缺点：
// 1. 参数难以调整（需要实验）
// 2. 可能产生"Peter Panning"（物体悬空）
// 3. 不同硬件/驱动可能有不同效果

// Peter Panning示例：
// 如果DepthBias太大：
// - 阴影离物体底部有间隙
// - 看起来像物体悬浮在空中

//     ┌───────┐
//     │ 木箱  │
//     └───────┘  ← 物体底部
//         ↕ 间隙
//     ███████████ ← 阴影（被推远）

// 最佳实践：
// - 从小值开始（100-1000）
// - 逐渐增加直到Z-Fighting消失
// - 检查是否有Peter Panning
// - 对于Chapter 14的场景，位置偏移更简单
```

### 7.6 解决方案4：提高深度缓冲区精度

```cpp
// 方案A：使用32位浮点深度

depthDesc.Format = DXGI_FORMAT_D32_FLOAT;  // ← 32位浮点（vs 24位整数）

// 优势：

// - 占用更多内存（33%增加）
// - 占用更多带宽
// - 无模板缓冲区（除非使用D32_FLOAT_S8X24_UINT）

// 方案B：使用反向Z技巧

// 传统深度：near=0.0, far=1.0
// - 精度集中在近处
// - 远处精度不足

// 反向深度：near=1.0, far=0.0
// - 精度分布更均匀
// - 减少远距离的Z-Fighting

// 设置反向Z：
// 1. 修改投影矩阵
XMMATRIX proj = XMMatrixPerspectiveFovLH(fov, aspect, farZ, nearZ);  // ← 交换near和far

// 2. 修改深度比较函数
depthDesc.DepthFunc = D3D11_COMPARISON_GREATER;  // ← GREATER（vs LESS）

// 3. 清除深度缓冲区为0.0
context->ClearDepthStencilView(dsv, D3D11_CLEAR_DEPTH, 0.0f, 0);  // ← 0.0（vs 1.0）

// 优势：
// - 几乎消除远距离Z-Fighting

// - 很多现代游戏引擎使用（Unreal、Unity）

// 缺点：
// - 需要修改渲染代码
// - 可能与某些中间件不兼容
```

## 8. 深度测试的高级应用

### 8.1 预Z-Pass技术

```cpp
// 预Z-Pass：先绘制一遍场景只填充深度缓冲区，再绘制颜色

// Pass 1: 深度预填充
void DepthPrePass()
{
    // 设置：只写深度，不写颜色
    D3D11_BLEND_DESC blendDesc;
    blendDesc.RenderTarget[0].RenderTargetWriteMask = 0;  // ← 禁止写颜色
    
    D3D11_DEPTH_STENCIL_DESC depthDesc;
    depthDesc.DepthEnable = TRUE;
    depthDesc.DepthWriteMask = D3D11_DEPTH_WRITE_MASK_ALL;  // ← 写深度
    depthDesc.DepthFunc = D3D11_COMPARISON_LESS;
    
    // 使用简单的顶点着色器（不需要像素着色器）
    context->VSSetShader(simpleVS, nullptr, 0);
    context->PSSetShader(nullptr, nullptr, 0);  // ← 无PS
    
    // 绘制所有不透明物体
    DrawOpaqueObjects();
}

// Pass 2: 颜色渲染
void ColorPass()
{
    // 设置：写颜色，深度测试但不写入
    D3D11_BLEND_DESC blendDesc;
    blendDesc.RenderTarget[0].RenderTargetWriteMask = 0xF;  // ← 写所有颜色
    
    D3D11_DEPTH_STENCIL_DESC depthDesc;
    depthDesc.DepthEnable = TRUE;
    depthDesc.DepthWriteMask = D3D11_DEPTH_WRITE_MASK_ZERO;  // ← 不写深度
    depthDesc.DepthFunc = D3D11_COMPARISON_EQUAL;  // ← 必须完全相等
    
    // 使用完整的着色器（包括光照计算）
    context->VSSetShader(fullVS, nullptr, 0);
    context->PSSetShader(fullPS, nullptr, 0);
    
    // 再次绘制所有不透明物体
    DrawOpaqueObjects();
}

// 优势：
// 1. Early-Z优化最大化（深度已知，大量片元被提前剔除）
// 2. 减少overdraw（像素着色器只执行一次）
// 3. 适用于复杂的像素着色器（如延迟渲染）

// 缺点：
// 1. 增加draw call数量（绘制两次）
// 2. 占用更多顶点带宽
// 3. 仅适用于深度值完全相同的场景（需要EQUAL比较）

// 适用场景：
// - 复杂的前向渲染（像素着色器开销大）
// - 延迟渲染的G-Buffer生成
// - 高overdraw的场景（如室内）
```

```cpp
void DepthPeelingPass1()
{

    // 在像素着色器中实现：
    float4 PS_DepthPeel(VertexOut pin) : SV_Target
    {
        // 读取前一层的深度
        float prevDepth = prevDepthTex.Sample(sampler, pin.tex);
        
        // 当前片元深度
        float currDepth = pin.posH.z;
        
        // 剔除前一层及更前的片元
        if (currDepth <= prevDepth)
            discard;
        
        // 绘制第二层
        return ComputeColor();
    }
    
    DrawTransparentObjects();
    
    // 结果：第二层的颜色和深度
    // colorTex1, depthTex1
}

// Pass 3-N: 继续剥离更深层
// ...

}
```

### 8.3 深度边界检测（Depth-Based Edge Detection）

```cpp
// 使用深度缓冲区检测物体边缘（如卡通渲染的轮廓线）

float4 PS_EdgeDetection(VertexOut pin) : SV_Target
{
    // 当前像素深度
    float depth = depthTex.Sample(sampler, pin.tex);
    
    // Sobel算子采样周围像素
    float2 texelSize = 1.0 / textureSize;
    
    // 3x3采样
    float d00 = depthTex.Sample(sampler, pin.tex + float2(-1, -1) * texelSize);
    float d01 = depthTex.Sample(sampler, pin.tex + float2(0, -1) * texelSize);
    float d02 = depthTex.Sample(sampler, pin.tex + float2(1, -1) * texelSize);
    
    float d10 = depthTex.Sample(sampler, pin.tex + float2(-1, 0) * texelSize);
    float d12 = depthTex.Sample(sampler, pin.tex + float2(1, 0) * texelSize);
    
    float d20 = depthTex.Sample(sampler, pin.tex + float2(-1, 1) * texelSize);
    float d21 = depthTex.Sample(sampler, pin.tex + float2(0, 1) * texelSize);
    float d22 = depthTex.Sample(sampler, pin.tex + float2(1, 1) * texelSize);
    
    // Sobel X方向
    float sobelX = d00 + 2*d10 + d20 - d02 - 2*d12 - d22;
    
    // Sobel Y方向
    float sobelY = d00 + 2*d01 + d02 - d20 - 2*d21 - d22;
    
    // 边缘强度
    float edge = sqrt(sobelX * sobelX + sobelY * sobelY);
    
    // 阈值判断
    if (edge > threshold)
        return float4(0, 0, 0, 1);  // 黑色轮廓线
    else
        return sceneTex.Sample(sampler, pin.tex);  // 原始颜色
```

```cpp
float3 ReconstructWorldPos_Method1(float2 screenUV, float depth)
{
```

```cpp
// Hi-Z：构建深度缓冲区的mipmap层次，用于快速遮挡剔除

// 构建Hi-Z金字塔
void BuildHiZPyramid()
{
    // Level 0：完整分辨率深度
    // 已经在正常渲染中填充
    
    // Level 1-N：逐级降采样
    for (int level = 1; level < mipLevels; ++level)
    {
        // 设置渲染目标为下一级mip
        context->OMSetRenderTargets(1, hiZRTV[level], nullptr);
        
        // 采样上一级的4个像素，取最远深度（最大值）
        context->PSSetShaderResources(0, 1, hiZSRV[level - 1]);
        context->PSSetShader(hiZDownsamplePS, nullptr, 0);
        
        DrawFullscreenQuad();
    }
}

// 降采样像素着色器
float PS_HiZDownsample(float2 uv : TEXCOORD) : SV_Target
{
    float2 texelSize = 1.0 / textureSize;
    
    // 采样2x2区域
    float d00 = prevLevel.Sample(sampler, uv + float2(0, 0) * texelSize);
    float d01 = prevLevel.Sample(sampler, uv + float2(1, 0) * texelSize);
    float d10 = prevLevel.Sample(sampler, uv + float2(0, 1) * texelSize);
    float d11 = prevLevel.Sample(sampler, uv + float2(1, 1) * texelSize);
    
    // 返回最大深度（最保守的遮挡）
    return max(max(d00, d01), max(d10, d11));
}

// 使用Hi-Z进行遮挡剔除
bool IsOccluded(BoundingBox bbox)
{
    // 投影包围盒到屏幕空间
    float2 screenMin, screenMax;
    float minDepth = ProjectBBox(bbox, screenMin, screenMax);
    
    // 计算应该采样的mip级别
    float2 size = screenMax - screenMin;
    int mipLevel = ceil(log2(max(size.x, size.y)));
    
    // 采样Hi-Z
    float occluderDepth = hiZTex.SampleLevel(sampler, (screenMin + screenMax) * 0.5, mipLevel);
    
    // 如果物体深度大于遮挡物深度，则被遮挡
    return minDepth > occluderDepth;
}

// 优势：
// - GPU端遮挡剔除（无需CPU回读）
// - 批量查询（一次采样覆盖多个像素）
// - 适用于大量小物体的场景
```

```cpp
        // 查找缓存
        auto it = m_DepthStates.find(hash);
        if (it != m_DepthStates.end())
        {
            // 检查是否需要切换
            if (it->second.Get() != m_CurrentState)
            {
                context->OMSetDepthStencilState(it->second.Get(), stencilRef);
                m_CurrentState = it->second.Get();
            }
            return;
        }
        
        // 创建新状态
        ComPtr<ID3D11DepthStencilState> newState;
        HR(device->CreateDepthStencilState(&desc, newState.GetAddressOf()));
        m_DepthStates[hash] = newState;
        
        context->OMSetDepthStencilState(newState.Get(), stencilRef);
        m_CurrentState = newState.Get();
    }
};

// 策略4.3：状态排序

struct DrawCommand
{
    GameObject* object;
    DepthStateID depthState;
    BlendStateID blendState;
    RasterStateID rasterState;
    float distanceToCamera;
};

void SortDrawCommands(std::vector<DrawCommand>& commands)
{
    std::sort(commands.begin(), commands.end(),
        [](const DrawCommand& a, const DrawCommand& b)
        {
            // 优先级1：深度状态（减少状态切换）
            if (a.depthState != b.depthState)
                return a.depthState < b.depthState;
            
            // 优先级2：混合状态
            if (a.blendState != b.blendState)
                return a.blendState < b.blendState;
            
            // 优先级3：距离（不透明物体从前到后，透明物体从后到前）
            return a.distanceToCamera < b.distanceToCamera;
        });
}
```

```cpp
private:

    ComPtr<ID3D11Query> m_EndQuery;

        desc.MiscFlags = 0;
        HR(device->CreateQuery(&desc, m_DisjointQuery.GetAddressOf()));

        desc.Query = D3D11_QUERY_TIMESTAMP;
        HR(device->CreateQuery(&desc, m_BeginQuery.GetAddressOf()));
        HR(device->CreateQuery(&desc, m_EndQuery.GetAddressOf()));
    }

    {
        context->Begin(m_DisjointQuery.Get());
        context->End(m_BeginQuery.Get());
    }
    
    void End(ID3D11DeviceContext* context)
    {
        context->End(m_EndQuery.Get());
        context->End(m_DisjointQuery.Get());
    }
    
    float GetTime(ID3D11DeviceContext* context)
    {
        // 等待GPU完成
        D3D11_QUERY_DATA_TIMESTAMP_DISJOINT disjoint;
        while (context->GetData(m_DisjointQuery.Get(), &disjoint, sizeof(disjoint), 0) == S_FALSE)
        {
            // 等待
        }
        
        if (disjoint.Disjoint)
            return -1.0f;  // 时间戳不可靠

        context->GetData(m_BeginQuery.Get(), &beginTime, sizeof(UINT64), 0);
        context->GetData(m_EndQuery.Get(), &endTime, sizeof(UINT64), 0);
        
        // 计算时间（毫秒）
        float time = float(endTime - beginTime) / float(disjoint.Frequency) * 1000.0f;
        return time;
    }
```

```
- 60fps目标，实际30fps
- GPU占用率高
- 卡顿
```

**原因分析**：
```cpp
// 使用GPU Profiler查找瓶颈

// 可能的瓶颈1：高overdraw
// - 查看Overdraw视图（RenderDoc、Nsight）
// - 如果overdraw > 5x，考虑优化

// 可能的瓶颈2：深度带宽
// - 高分辨率 + 多个pass → 大量深度读写
// - 1920x1080 * 7 passes * 4 bytes = 56MB每帧

// 可能的瓶颈3：像素着色器复杂
// - 光照计算、纹理采样多
// - 使用预Z-Pass减少PS执行次数

// 可能的瓶颈4：Draw call过多
// - 每个物体单独draw
// - 状态切换频繁

// 可能的瓶颈5：没有遮挡剔除
// - 绘制所有物体，包括看不见的
```

**优化步骤**：
```cpp
// 步骤1：测量各个Pass的时间

GPUTimer timer;

// 测量镜子Pass
timer.Begin(context);
RenderMirrorPasses();  // Pass 1-5
timer.End(context);
float mirrorTime = timer.GetTime(context);

// 测量正常Pass
timer.Begin(context);
RenderNormalPasses();  // Pass 6-8
timer.End(context);
float normalTime = timer.GetTime(context);

// 分析：
// 如果 mirrorTime > 5ms → 镜子Pass是瓶颈
// 如果 normalTime > 10ms → 正常Pass是瓶颈

// 步骤2：针对性优化

// 如果镜子Pass慢：
// - 降低镜子分辨率
// - 限制反射物体数量
// - 简化反射物体LOD

// 如果正常Pass慢：
// - 前向后排序（利用Early-Z）
// - 遮挡剔除
// - LOD系统

// 步骤3：减少overdraw

// 方法1：前向后排序
SortOpaqueObjects_FrontToBack();

// 方法2：预Z-Pass
DepthPrePass();  // 只写深度
ColorPass();     // 只写颜色（深度测试但不写入）

// 方法3：遮挡剔除
for (auto& obj : objects)
{
    if (!IsCulled(obj))
        obj.Draw();
}

// 步骤4：批量绘制

// ❌ 每个物体单独绘制
for (auto& obj : objects)
{
    SetState(obj.state);
    obj.Draw();
}

// ✅ 批量绘制相同状态
for (auto& state : states)
{
    SetState(state);
    for (auto& obj : objectsWithState[state])
    {
        obj.Draw();
    }
}

// 步骤5：使用Instancing

// ❌ 多次draw call
for (int i = 0; i < 100; ++i)
{
    SetTransform(transforms[i]);
    DrawMesh(mesh);  // 100次draw call
}

// ✅ 一次draw call
DrawMeshInstanced(mesh, 100, transforms);  // 1次draw call
```

## 总结

Chapter 14 **Depth Test** 在 Chapter 13 的基础上，深入讲解了**深度测试的控制**和**深度缓冲区的高级应用**。

### 核心内容

1. **深度测试 vs 深度写入**
   - 深度测试：决定片元是否绘制
   - 深度写入：决定片元深度是否写入缓冲区
   - 两者独立控制，满足不同需求

2. **闪电动画**
   - 60帧BMP动画循环播放
   - 圆柱体几何（无顶盖/底盖）
   - 关闭深度写入，允许自身混合

3. **Z-Fighting处理**
   - 位置偏移（木箱+0.01，闪电+2.01）
   - 阴影平面偏移（Y=0.99）
   - 深度精度与近远平面的关系

4. **新增渲染模式**
   - `SetDrawBoltAnimNoDepthTest`：关闭深度测试
   - `SetDrawBoltAnimNoDepthWrite`：关闭深度写入
   - 带模板测试的变体

5. **7-Pass渲染**
   - 扩展Chapter 13的6-Pass
   - 增加反射闪电（Pass 4）和正常闪电（Pass 8）
   - 模板测试限制反射区域

### 关键技术点

```cpp
// 1. 深度测试控制
DepthEnable = TRUE;              // 启用测试
DepthWriteMask = ZERO;           // 关闭写入
DepthFunc = LESS;                // 比较函数

LOD_System();                            // 细节层次
```
