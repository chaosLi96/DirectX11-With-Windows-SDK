# Chapter 14: Depth Test 学习总结

## 核心内容
深度测试优化技术，包括**Early-Z**和**Z-PrePass**。

### Z-PrePass技术
1. **第一遍**：只写深度，不写颜色
   - OMSetBlendState(BSNoColorWrite)
   - 绘制所有不透明物体
2. **第二遍**：正常渲染
   - 深度测试EQUAL
   - 像素着色器只对可见像素执行

### 代码实现
\\\cpp
// Pass 1: Depth-only
m_pd3dImmediateContext->OMSetBlendState(RenderStates::BSNoColorWrite.Get(), nullptr, 0xFFFFFFFF);
m_pd3dImmediateContext->OMSetDepthStencilState(nullptr, 0);
DrawOpaqueObjects();

// Pass 2: Color rendering
m_pd3dImmediateContext->OMSetBlendState(nullptr, nullptr, 0xFFFFFFFF);
m_pd3dImmediateContext->OMSetDepthStencilState(RenderStates::DSSDepthEqual.Get(), 0);
DrawOpaqueObjectsWithShading();
\\\

### 性能优化
- Early-Z剔除被遮挡片段
- 减少像素着色器overdraw
- 适用于复杂光照场景
