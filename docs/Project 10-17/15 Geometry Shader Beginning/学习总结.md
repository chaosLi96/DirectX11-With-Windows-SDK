# Chapter 15: Geometry Shader Beginning 学习总结

## 核心内容
**几何着色器(Geometry Shader, GS)**是渲染管线中位于顶点着色器和像素着色器之间的可选阶段，可以生成、修改或删除几何图元。

### 1. GS基础

#### 输入输出拓扑
\\\hlsl
// 输入：三角形，3个顶点
[maxvertexcount(6)]  // 最多输出6个顶点
void GS(triangle VertexOut gIn[3], inout TriangleStream<GeoOut> triStream)
{
    // 处理每个三角形
    for (int i = 0; i < 3; ++i)
    {
        GeoOut gOut;
        gOut.posH = gIn[i].posH;
        gOut.color = float4(1,0,0,1);
        triStream.Append(gOut);
    }
    triStream.RestartStrip();
}
\\\

### 2. 典型应用

#### 2.1 法线可视化
\\\hlsl
[maxvertexcount(2)]
void GS_ShowNormal(point VertexOut gIn[1], inout LineStream<GeoOut> lineStream)
{
    // 起点：顶点位置
    GeoOut start;
    start.posH = mul(float4(gIn[0].posW, 1.0f), gViewProj);
    lineStream.Append(start);
    
    // 终点：沿法线方向
    float3 endPos = gIn[0].posW + gIn[0].normalW * 0.5f;
    GeoOut end;
    end.posH = mul(float4(endPos, 1.0f), gViewProj);
    lineStream.Append(end);
}
\\\

#### 2.2 线框模式(Wireframe)
\\\hlsl
[maxvertexcount(6)]
void GS_Wireframe(triangle VertexOut gIn[3], inout LineStream<GeoOut> lineStream)
{
    // 绘制3条边
    for (int i = 0; i < 3; ++i)
    {
        int next = (i + 1) % 3;
        lineStream.Append(Convert(gIn[i]));
        lineStream.Append(Convert(gIn[next]));
        lineStream.RestartStrip();
    }
}
\\\

#### 2.3 Billboard生成
\\\hlsl
[maxvertexcount(4)]
void GS_Billboard(point VertexOut gIn[1], inout TriangleStream<GeoOut> triStream)
{
    float3 center = gIn[0].posW;
    float3 up = float3(0,1,0);
    float3 look = normalize(gEyePosW - center);
    float3 right = cross(up, look);
    
    float halfWidth = 0.5f;
    float halfHeight = 0.5f;
    
    // 4个角点
    float4 v[4];
    v[0] = float4(center + halfWidth * right - halfHeight * up, 1.0f);
    v[1] = float4(center + halfWidth * right + halfHeight * up, 1.0f);
    v[2] = float4(center - halfWidth * right - halfHeight * up, 1.0f);
    v[3] = float4(center - halfWidth * right + halfHeight * up, 1.0f);
    
    // 输出2个三角形
    GeoOut gOut;
    for (int i = 0; i < 4; ++i)
    {
        gOut.posH = mul(v[i], gViewProj);
        gOut.tex = float2((i%2), (i/2));
        triStream.Append(gOut);
    }
}
\\\

### 4. 性能考虑

**GS性能开销：**
- 每个图元都经过GS处理
- 输出顶点数量影响性能
- 不支持Early-Z优化

**优化建议：**
1. 尽量减少GS输出顶点数
2. 简单几何操作用GS，复杂的用Instancing
3. 考虑使用Compute Shader替代

### 5. 常见问题

**Q1: maxvertexcount设置多大？**
A: 根据实际需求，越小越好。Billboard=4，法线=2，线框=6

**Q2: 为什么FPS下降？**
A: GS是性能瓶颈，减少输出顶点或改用其他技术

**Q3: 如何调试GS？**
A: 使用Graphics Debugger，查看每个图元的输出
